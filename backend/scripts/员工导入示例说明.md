# 员工导入示例文件说明

## 📁 文件说明

本目录包含一个员工导入示例文件：`员工导入示例.csv`

## 🎯 使用方法

### 方法1：转换为Excel格式（推荐）

1. 在Excel中打开 `员工导入示例.csv`
2. 另存为 `.xlsx` 格式
3. 编辑员工信息
4. 通过Web管理端上传

### 方法2：使用系统生成的模板（推荐）

1. 访问Web管理端：`http://localhost:5173/users/import`
2. 点击"下载员工导入模板"按钮
3. 系统会自动下载标准的Excel模板文件
4. 填写员工信息后上传

## 📋 字段说明

| 列名 | 是否必填 | 说明 | 示例 |
|------|---------|------|------|
| 姓名 | ✅ 必填 | 员工姓名，将作为登录账号 | 张三 |
| 身份证号 | ✅ 必填 | 至少4位，用于密码生成 | 110101199001011234 |
| 部门名称 | ✅ 必填 | 员工所属部门 | 技术部 |
| 部门号 | ⭕ 可选 | 部门编号 | DEPT001 |
| 上级姓名 | ⭕ 可选 | 直属上级的姓名 | 李四 |
| 手机号 | ⭕ 可选 | 联系电话 | 13800138000 |
| 邮箱 | ⭕ 可选 | 电子邮箱 | zhangsan@example.com |
| 角色 | ⭕ 可选 | 默认为FieldEngineer | FieldEngineer |

## 🔐 密码生成规则

系统会自动为每个员工生成初始密码：

**密码 = 姓名拼音 + 身份证后4位**

示例：
- 张三 + 1234 → `zhangsan1234`
- 李四 + 2345 → `lisi2345`
- 王五 + 3456 → `wangwu3456`

## 🎨 角色类型

| 角色代码 | 角色名称 | 说明 |
|---------|---------|------|
| FieldEngineer | 现场工程师 | 创建工单、上传证据、验证 |
| CS | 客服 | 创建工单、客户沟通 |
| SeniorEngineer | 高级工程师 | 分诊、创建解决方案 |
| Admin | 管理员 | 系统管理、所有权限 |

## ⚠️ 注意事项

1. **上级关系**：
   - 如果上级在同一批次导入，上级应该在员工之前的行
   - 如果上级已存在于系统中，直接填写上级姓名即可

2. **CSV格式**：
   - 使用UTF-8编码
   - 第一行为标题行
   - 空行会被自动跳过

3. **导入后**：
   - 所有账户默认处于"未开通"状态
   - 需要管理员在"账户开通审核"页面手动开通
   - 开通后员工才能使用初始密码登录
