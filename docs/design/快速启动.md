# 快速启动指南

## 启动后端服务

### 1. 确保依赖服务运行

**PostgreSQL:**
```bash
brew services start postgresql@16
```

**Redis:**
```bash
brew services start redis
```

**MinIO (可选):**
```bash
docker start minio
# 或首次启动: docker run -d -p 9000:9000 -p 9001:9001 --name minio -e "MINIO_ROOT_USER=minioadmin" -e "MINIO_ROOT_PASSWORD=minioadmin" minio/minio server /data --console-address ":9001"
```

### 2. 启动后端 API

```bash
cd backend
./start-dev.sh
```

或者手动启动：
```bash
cd backend/src/FieldTicket.Api
dotnet run --environment Development
```

后端服务将在 **http://localhost:5000** 启动

### 3. 启动前端开发服务器

在另一个终端窗口：

```bash
cd web-admin
npm install  # 首次运行需要
npm run dev
```

前端将在 **http://localhost:3000** 启动

## 访问地址

- **前端页面**: http://localhost:3000
- **后端 API**: http://localhost:5000
- **Swagger 文档**: http://localhost:5000/swagger
- **MinIO 控制台**: http://localhost:9001

## 开发模式

在开发模式下，前端提供了"开发模式：跳过登录"功能，无需配置企业微信即可测试。
