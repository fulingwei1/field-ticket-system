## 📝 技术细节

### 关联分析算法

**相似工单**：
- 复用 `DuplicateDetectionService` 的相似度计算
- 综合评分：设备(40%) + 症状(30%) + 问题域(20%) + 时间(10%)
- 只返回相似度 >= 0.5 的工单

**设备关联**：
- 直接查询 `DeviceId` 相同的工单
- 排除条件：自己、草稿、已合并、已标记为重复

**客户关联**：
- 直接查询 `CustomerId` 相同的工单
- 排除条件：自己、草稿、已合并、已标记为重复

**问题域关联**：
- 查询 `Domain` 和 `StepCode` 都相同的工单
- 排除条件：自己、草稿、已合并、已标记为重复

### 前端展示

**标签页组织**：
- 全部：显示所有关联工单，带关联类型标签
- 相似：只显示相似工单，带相似度进度条
- 设备：只显示设备关联工单
- 客户：只显示客户关联工单
- 问题域：只显示问题域关联工单

**相似度可视化**：
- 使用 `Progress` 组件显示相似度百分比
- 颜色区分：
  - 绿色：>= 70%（高相似度）
  - 橙色：50-70%（中相似度）
  - 红色：< 50%（低相似度）
