## 案例特点

### 真实性
- 所有案例均基于非标自动化行业真实场景
- 涵盖FCT测试、EOL测试、自动化装配等典型应用
- 问题描述详细，包含技术细节和现场情况

### 完整性
- 每个案例包含完整的问题域分类
- 包含复现性信息（复现率、重启恢复、环境相关）
- 包含版本信息（软件、PLC、参数、硬件）
- 包含结构化事实（JSON格式）
- 包含现场已执行动作和说明

### 多样性
- 覆盖5个问题域（A/B/C/D/E）
- 涵盖多个行业和应用场景
- 包含不同优先级和复杂程度的问题
- 包含偶发问题和持续性问题

## 使用说明

### 查看案例文档
详细案例描述请参考：`docs/test-data/INDUSTRY_CASES.md`

### 查询数据库中的案例
```sql
-- 查看所有案例
SELECT ticket_no, domain, step_name, symptom_title, status, priority 
FROM tickets 
WHERE ticket_no LIKE 'TK-%' 
ORDER BY created_at;

-- 按问题域统计
SELECT domain, COUNT(*) as count 
FROM tickets 
WHERE ticket_no LIKE 'TK-%' 
GROUP BY domain 
ORDER BY domain;

-- 查看特定行业的案例
SELECT ticket_no, symptom_title 
FROM tickets 
WHERE ticket_no LIKE 'TK-%' 
AND symptom_title LIKE '%汽车电子%';
```

### 导入案例到系统
案例已通过SQL脚本自动导入到数据库，可以直接在系统中查看和使用。

## 案例编号规则

- 格式：`TK-YYYYMMDD-NNN`
- 示例：`TK-20251228-001` 到 `TK-20251228-020`
