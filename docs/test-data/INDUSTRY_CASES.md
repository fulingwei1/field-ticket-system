# 非标自动化行业真实案例集

本文档包含20个详细的非标自动化行业真实案例，涵盖汽车电子测试、锂电池EOL测试、白色家电测试、电动工具、电机驱动器、BMS测试设备、FCT测试和控制板自动化装配等领域。

## 案例分类说明

- **问题域A（机械/动作）**：机械结构、运动控制、定位精度、装配动作等
- **问题域B（电气/IO）**：电气连接、IO信号、传感器、执行器、电源等
- **问题域C（PLC/程序）**：PLC程序逻辑、流程控制、时序问题、通信协议等
- **问题域D（测试/判定）**：测试判定逻辑、测试结果异常、判定标准等
- **问题域E（系统/环境）**：系统级问题、环境因素、偶发故障等

## 总结

以上40个案例（案例1-20 + 案例21-40）涵盖了非标自动化行业的典型问题场景：

1. **机械/动作问题（A域）**：定位精度、探针接触、装配定位、贴片位置、夹具磨损、视觉识别等
2. **电气/IO问题（B域）**：电流波动、电压采集、传感器故障、通信超时、负载控制、继电器故障等
3. **PLC/程序问题（C域）**：程序逻辑错误、超时处理、控制逻辑、通信协议、测试序列等
4. **测试/判定问题（D域）**：测试判定逻辑、重复性、数据异常、效率计算、保护误触发等
5. **系统/环境问题（E域）**：偶发故障、环境因素、系统级问题、数据同步等

这些案例可以作为工单系统的测试数据，帮助验证系统的完整性和准确性。
